## Reflection
The SmartCare appointment system prototype examined how the patient, practitioner names and appointment times may be stored and displayed. The enhanced version used a list, dictionaries and functions and identified a few limitations including validation and possible double bookings.

Microsoft Copilot was then asked to be a tutor to explain the code, identify possible problems and suggest improvements. Some of the suggestions proved to be useful especially the validations suggestions, however the AI took assumptions so all suggestions could not be accepted.

The code was verified by running it through different scenarios, including empty values, None values and a double booking scenario.

At the end it was my responsibility to understand the requirements of the request, evaluate the suggestions from AI, test and then decide what was appropriate, making sure I could explain the code.
